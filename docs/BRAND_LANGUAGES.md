# Skelly language naming and product boundaries

**This is a naming decision, not an instruction to rename existing code or files.**

## Skellenese — culture and lore
- Canonical spelling: **Skellenese** (two Ls), pronounced roughly *Skell-uh-neez*.
- Skelly's invented skeleton vocabulary, shared expressions, lyrics, voice tags, in-world lore and fan activities.
- Cultural applications: New Era releases, The Graveyard collective, Discord challenges, Song Wars, SkellWorld, videos and merch.
- Build a reviewed living dictionary with origins, definitions, examples, accessible translations and contributor permission.
- The first words are **not** final canon until reviewed and approved.

## SkellCipher — artistic secret-writing system
- A fictional graphical alphabet / coded puzzle layer for Skellenese.
- Use for artwork easter eggs, scavenger hunts, encoded captions and community events.
- **Not cryptography**. Never use it in place of encryption, authentication, secure tokens or confidentiality.

## SkellLang — programming language
- Product name of the SkellForge declarative design/compiler language. Source extension remains **.skell**.
- Version 1 language header remains `skell 1`.
- Composes visual layout, DSP graph and parameter-mapped components. Produces the validated Studio design model and current JUCE VST3 output.
- Keep keywords stable and readable. Skellenese-themed editor skins may be optional decoration, never a change to parser semantics or saved automation.
- **Never** silently rename existing plugin identities, C++ classes, .skell statements, or host parameter IDs.

## Engineering boundary
Skellenese and SkellCipher belong to the cultural and media side of SkellWorld. SkellLang belongs to the SkellForge developer tooling. SkellNative SDK is the independent C++17 audio/host contract prototype. A direct VST3 backend must still comply with the Steinberg VST3 interface, regardless of which Skelly language authors a design.

## Review rules
- New glyphs need original artwork and intellectual-property review.
- Credit/permission fan submissions and keep contest rules accessible.
- Preserve readable text alternatives to pictograms.
- Do not imply SkellCipher secures data.
- Protect existing production DAW sessions and plugin IDs throughout naming work.

Cultural rollout: seed dictionary, alphabet concepts, a limited opt-in Discord decode event, one New Era teaser, then measure actual engagement before spending money on merchandise.
